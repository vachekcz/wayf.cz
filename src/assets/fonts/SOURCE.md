# VT323

VT323 Regular (400), distributed under the SIL Open Font License 1.1 in
[VT323-OFL.txt](../../../public/fonts/VT323-OFL.txt). Copyright 2011, The VT323
Project Authors. The license is served at `/fonts/VT323-OFL.txt` so it accompanies
the deployed font files.

These unmodified WOFF2 subsets were downloaded from Google Fonts on 2026-09-11:

- Latin: https://fonts.gstatic.com/s/vt323/v18/pxiKyp0ihIEF2isfFJXUdVNF.woff2
- Latin Extended: https://fonts.gstatic.com/s/vt323/v18/pxiKyp0ihIEF2isRFJXUdVNFKPY.woff2
- Stylesheet and Unicode ranges: https://fonts.googleapis.com/css2?family=VT323&display=swap
- License source: https://github.com/google/fonts/blob/main/ofl/vt323/OFL.txt

Both subsets are required for the site's Czech and English text. The Latin subset
is preloaded for the main heading; CSS loads Latin Extended when needed. Keep
the matching Unicode ranges in `src/styles/global.css` when updating the files.
